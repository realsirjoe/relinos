# Contributing

We love contributions! There are several ways to help improve Relinos:

- **Share routines and extractions** you've created by submitting a pull request to the [Relinos Registry](https://github.com/realsirjoe/relinos_registry).
- **Report bugs or suggest features** by opening a [GitHub issue](https://github.com/realsirjoe/relinos/issues).
- **Contribute code or documentation** by submitting a pull request.

Whether it's a small fix, a new feature, or a reusable website API, all contributions are appreciated.
